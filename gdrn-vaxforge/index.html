Scientific research core · Stage 2

The v0.2 Python package adds explicit NCBI/UniProt accession acquisition with provenance, sequential QC/conservation analysis, and paired group-aware model benchmarking. Those server-side research tools do not run from this static browser page. External immunoinformatics predictions are not submitted automatically.

Versioned configurations, supplementary outputs and reproducibility manifest.

GDRN-VaxForge is experimental scientific software, not a clinical device. Biological validity, safety, immune protection and clinical benefit cannot be established by this demonstration. External scientific prediction services are not yet automatically connected; acquisition requires an explicit local Python command. Original paper foundation: Vaccines (2023), 11, 1090.
