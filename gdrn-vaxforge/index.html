Sequence analysis workbench

Explore FASTA sequences, compare an existing multiple-sequence alignment and export reproducible conservation reports. Run real analyses directly in your browser.

Scientific scope

This version provides actual sequence quality control and descriptive comparison of already aligned sequences. It does not generate a multiple-sequence alignment, discover epitopes, construct vaccines or predict immune protection.

Your pasted and uploaded sequence data are not sent to the GDRN server. Public UniProt accession retrieval sends only the requested accession to UniProt.

01 · Input and parameters

Start analysis

One or more FASTA records. Up to 500 records and 3 million sequence characters; no patient-identifying data.

UniProt retrieval requires internet access and browser permission. The import does not align sequences.
