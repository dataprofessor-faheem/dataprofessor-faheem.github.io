# GDR-MaizeGP

**GDR Maize Genome & Proteome Browser** is a static, research-oriented maize bioinformatics portal deployed through GitHub Pages.

## v1.0 features
- Interactive B73 NAM 5.0 genome browsing through hosted JBrowse 2
- B73 reference metrics and official assembly accession
- Live UniProtKB protein search for *Zea mays* (Taxonomy ID 4577)
- Direct FASTA links for retrieved UniProt entries
- Curated Indian maize germplasm metadata from ICAR
- Explicit separation of cultivar metadata from verified genome assemblies
- Machine-readable source provenance manifest

## Reference backbone
- Organism: *Zea mays*
- Assembly: Zm-B73-REFERENCE-NAM-5.0
- NCBI accession: GCF_902167145.1
- Official current MaizeGDB gene model set: Zm00001eb.1

## Scientific integrity
No Indian cultivar is presented as having an integrated genome assembly unless a public authoritative accession has been verified. Current Indian cultivar entries are metadata records only.
