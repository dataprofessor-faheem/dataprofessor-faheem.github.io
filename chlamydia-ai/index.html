Five-model teacher system

What each model contributes

CellSAM

Generalist host-cell segmentation. Proposed primarily for HeLa-cell boundary masks and morphology.

Cellpose-SAM / CPDINO

General cellular instance segmentation and strong morphology representation for cells and candidate inclusions.

micro-SAM

Microscopy-adapted interactive and automatic segmentation for annotation refinement and hard examples.

StarDist

Geometry-driven instance segmentation baseline for compact fluorescence-associated structures.

YOLO26-seg

Fast deployable student after Chlamydia-specific fine-tuning and teacher knowledge distillation.

MathFusion layer

Learns calibrated teacher weights, quantifies disagreement and distills consensus into a lighter student.

Mathematical upgrade

Calibrated, geometry-aware learning

q(y|x) = Σₖ wₖ pₖ(y|x), wₖ = exp(aₖ) / Σⱼ exp(aⱼ) L = λ₁ L_Focal-Tversky + λ₂ L_Dice + λ₃ L_Boundary + λ₄ L_SDF + λ₅ L_KD + λ₆ L_CrossModal + λ₇ L_Brier L_cross = JS(P_Giemsa, P_DFA) + η Wε(E_Giemsa, E_DFA) Uncertainty = predictive entropy + teacher disagreement

Teacher weights are learned on validation data under a simplex constraint. Cross-modality consistency can use Jensen–Shannon divergence and, where paired fields are available, entropy-regularized optimal transport between image representations.

Required validation

Dice, IoU, precision, recall, F1, AP50, AP50–95, count agreement, calibration/Brier score, inference time and experiment-level bootstrap confidence intervals.

Leakage control

Train/validation/test splitting must occur by experiment, plate, well or biological replicate—not by random crops from the same microscopy field.
