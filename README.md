# Research & Data Portal

This repository hosts a free public website using GitHub Pages.

## Website structure
- `index.html` — main website
- `assets/style.css` — design
- `assets/app.js` — website behavior
- `data/content.json` — editable website content
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment

## Future custom domain
A purchased domain can later be connected to this same GitHub Pages website without rebuilding it.

## Data note
GitHub is not a transactional database. This starter uses `data/content.json` as a small public version-controlled data store. For logins, contact-form submissions, or live shared records, connect a backend such as Supabase later.
